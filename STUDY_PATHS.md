# Scripture study paths

New Game: Press Start → existing Scripture Collection → Study Path → existing Player Name → Begin Game. There are three unselected ordered choices; no name submission can create a run before both scope choices are valid. Back goes Name → Study Path → Collection → Title. Drafts survive navigation; changing collection clears the study draft. Choosing a path is always deliberate, with no checked/default button. `openPlayerName()` is the insertion point for future character selection; no character screen or new character is added.

Runs store `scriptureCollection` and `studyPath` (`complete`, `ot`, `nt`) in the existing version-3 local save. Missing study metadata defaults to `complete`; missing collection metadata retains the existing `kjv80` default. Retry never changes either. Validation rejects out-of-scope saved queues/answers and unknown path IDs rather than silently converting them. Existing scores, ranks, legitimate equipment, achievements and overwrite confirmation are preserved.

`study-paths.js` combines existing canonical book metadata with the collection filter. Restricted paths inspect primary/supporting citations plus all approved visible text and retained lesson title/context/objective text. Cross-testament records are excluded whole, never rewritten, shortened or duplicated. Full-book-name matching intentionally errs toward exclusion when a named book is also a person's name. Future imported abbreviations/unstructured allusions still need editorial review; citation presence alone never establishes textual accuracy. [Inventory and exclusions](content/STUDY_PATH_AUDIT.md) documents the 260/185/39 and 250/177/39 pools and difficulty limits.

Selection keeps the existing spacing, misses, disclosure-conflict guards, category weighting, difficulty targets and fresh-retry avoidance. It has no new retry loops. All six real pools support ten distinct non-conflicting questions; constrained/invalid synthetic pools fail with the existing bounded descriptive error instead of falling outside the canon or spinning. In NT-only, no complexity 4–7 records currently survive the strict scope audit, so advanced gameplay falls back to approved lower-complexity questions. No zero-repetition or advanced-content guarantee is made.

## Kingdom milestone

Kingdom entry/transformation and its completion achievement are still **not implemented** in the existing game; see GAME_PROGRESSION.md. Complete Scripture retains eligibility through `kingdomEligible(run)`. OT-only and NT-only return false and never receive a new Kingdom completion grant. Existing profile achievements are not deleted.

After an alternate-path player successfully clears Level 700, the existing victory presentation now explicitly announces that study path's completion, preserves every earned reward and offers the usual optional continuation to Level 701. Reaching Level 700 or losing there does not show completion. There is no hidden conversion, mandatory restart or endless requirement. Complete Scripture's existing Level 700 behavior is unchanged. Any future Kingdom-entry/reward implementation must use the exported eligibility guard; this task does not claim that the future full Kingdom phase is playable.
