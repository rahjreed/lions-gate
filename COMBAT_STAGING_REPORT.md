# Combat staging review — 2026-10-25

## Changes

- Matched visible character size instead of comparing transparent atlas rectangles. Judah is larger relative to his old battlefield presentation; the soldier retains his original artwork. Both now use the same arena-relative sizing system on desktop and mobile.
- Aligned visible feet to a shared ground line. The soldier's six source frames have different transparent foot margins; per-frame offsets compensate for them, including the lower atlas row used for recoil and recovery.
- Increased idle body-center separation to 128 arena units. A unit follows arena height, with a width cap for narrow containers. The characters remain centered as a pair.
- Correct answer: existing Judah run frames close the gap, the original sword sequence anticipates/contact/follows through, then existing walk frames provide a backward recovery. Incorrect/timeout/shield: the soldier makes a short advancing step-lunge, Judah recoils, and both return home.
- Kept the 240ms impact and 920ms normal exchange. Travel is continuous across sprite changes because `paintCombat` updates the figure's contents without replacing the travelling figure. No additional impact/damage callback was introduced.
- Finishing blows retain the existing 540ms fall start and 760ms fall duration. The fall moves away from Judah; the reveal still waits until it finishes.
- Enemy name is now right-aligned at the far end of the enemy health bar, with the percentage on the left. Long titles wrap without covering the value.

No sprite PNGs, scoring, lives, shield calculations, timers, question logic, ranks, achievements or local-save modules were changed. `sw.js` was regenerated by the existing production build to cache the updated presentation files.

- The soldier still uses his existing six-pose atlas. His advance is a short step-lunge, not a newly drawn walking cycle; adding a detailed enemy locomotion cycle would require a separate art task. No atlas was regenerated here.
