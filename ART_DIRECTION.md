# Console raster art upgrade

This pass changes presentation only. Engine, questions, ranks, persistence, gameplay DOM structure, and sound scheduling retain their existing contracts.

Judah now uses original 96×160-pixel PNG frame strips, one for each of five earned ranks. Each sheet has sixteen frame slots: four idle, four success, four reflective miss, and four promotion frames, including intentional holds. Idle includes breathing, a small head shift, and a blink. Success and promotion raise a hand across the chest; a miss lowers and turns the head. Playback uses discrete CSS background positions, not interpolated vector limbs. Reduced-motion mode presents a static appropriate reaction frame.

His design retains brown skin and dreadlocks, now with six-tone facial shading, cheek and nose planes, eyes, beard, individual lock highlights and cuffs, split collars, cloth folds and seams, boot laces, a staggered stance, and more visible rank silhouettes. Novice wears a short woven tunic; Student gains a blue-green sash; Scholar a longer blue robe and bound book; Scribe a teal outer robe and scroll; Master an ivory robe with purple/gold shoulder mantle and jeweled clasp. Degree labels and a capped eight-diamond insignia distinguish later Master degrees without implying infinitely unique costumes.

Five original 640×280 raster worlds replace the simple SVG scenes. Each has three faceted distance planes, a palette-banded/dithered sky, cratered moon, textured terrace tiles, chipped masonry, shaded column channels, engraved panels, book crest and stepped lintel details. Highlands add layered cedars; Starlight adds water reflections and a small distant sail; Citadel adds towers; Observatory adds domes and lit windows. Separate four-frame fire strips and star glints provide restrained motion. A shared aspect-ratio plane keeps flame overlays aligned with their mounts while scenes crop responsively.

Sword art has a faceted blade, central fuller, metallic highlights, shaped crossguard, wrapped grip and jeweled pommel. UI has hard-edged inset bevels, layered metal/stone borders, dimensional answer keys, segmented gold button shading, a deeper title emboss, lighter scanlines, and a short stepped scene arrival. Question text retains legible typography.

All PNG assets are original integer-coordinate drawing authored in `scripts/build-pixel-art.py`. No game assets, AI image sources, downloaded sprite packs, or third-party visual IP are used. Regenerate with Python and Pillow only when intentionally editing artwork; the published static site needs neither. PNG files are checked in, totaling approximately 104 KiB. Runtime uses native image decoding and small CSS animations, without a canvas loop, per-pixel JavaScript, or new libraries.

Verification: all six existing Node suites pass; all twelve PNG files decode, all eighty character frame slots are occupied, correct/miss silhouettes differ, and sprite alpha values contain no antialiasing. Desktop title/Armory and narrow-screen title/gameplay were visually inspected; viewport width equals scroll width. No browser errors were observed.

Limits: this is an original console-inspired browser presentation, not a hardware palette/tile/DMA emulator. Background depth planes are baked into the raster rather than independently scrolling. Judah has four presentation states rather than a full walking/combat animation set; degrees beyond the five core outfits reuse the Master mantle. Raster pixels use nearest-neighbour display, but fractional responsive scales can create uneven pixel widths. Content and scoring are unchanged.
