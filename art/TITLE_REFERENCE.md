# Approved title reference implementation

The owner's October 31, 2026 Gemini image is the composition reference. The
title-only CSS layers a scenery illustration behind existing live title text,
Judah's rank-aware animated sprite, the floating sword and real menu buttons.
The separate player-name screen and all navigation handlers remain unchanged.

`dist/assets/console/title-gate-reference.png` was generated with the built-in
image tool using the owner's screenshot as an edit reference. It is scenery
only, not a screenshot of the interface. No external runtime image URL is used.

Prompt: Extract/recreate only the inner illustrated gate scene at approximately
1.30:1. Preserve the dark starry sky, crescent moon, tall narrow distant castle
behind mountains on the right, layered mauve/blue mountains, weathered stone
gate pillars, vines, lintel, centered steps, torches and bottom-right fire. Remove
all lettering, captions, borders, menus, buttons, Judah and swords; reconstruct
the scenery beneath them. Leave upper sky for live lettering, the left foreground
for Judah, and the center for the sword. Match the approved composition and
refined early-1990s pixel-art shading; no modern vector or blurry painted style.

Known differences: the derived scenery is not pixel-identical to the reference;
the original game Judah and sword sprites are deliberately retained, including
earned wardrobe/armor appearance. Live HTML gold lettering and button bevels
approximate the illustrated reference rather than rasterizing its text. Short
screens retain normal vertical scrolling if needed instead of clipping controls.
